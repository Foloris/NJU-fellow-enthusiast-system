    # 项目开发规则
    
    ## 技术栈
    - Vue 3 + TypeScript + Go
    - 数据库使用MySql
    
    ## 开发约束
    - 修改前先阅读相关代码
    - 不随意引入新依赖
    - 不使用 any 绕过类型检查
    - 优先复用已有组件
    - 有任何疑问及时报告
    ##重构约束：
        后端必须重构为go为基础的简洁明了的简单分层架构，不要遗留旧项目的影响
    ## 验证要求
    - 修改后运行类型检查
    - UI 修改需要浏览器验证
    
    ## 输出要求
    - 简单的解释修改了哪些文件
    - 说明测试结果
    - 输出一个测试说明.md，方便人员手动调试和测试，并注明需要准备的环境配置。
